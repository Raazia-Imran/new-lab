# Visual assets and motion

The redesign takes inspiration from the SVGator animation reference and Framer industrial presentation patterns. No Framer template code, template photographs or third-party animated artwork was copied.

- Original generated artwork: /images/simulation-art.webp. It is conceptual illustration, not measured simulation output. Brief: atomic crystal to finite-element lattice to fluid-flow ribbon, restrained orange and indigo, midnight navy, no text, no logos. The original generation is retained separately; the optimized web version is committed here.
- Lab logo and six client logos: supplied source assets, unchanged. Client identities/relationships and permission for public use still require confirmation.
- NED emblem/wordmark: downloaded from the official university homepage asset https://www.neduet.edu.pk/sites/default/files/ONLYLOGO_1.png . Institutional marks are used for the requested university lab branding; client authorization should be confirmed before launch. This is not a public-domain or blanket copyright-free claim.
- Favicon: original vector adaptation of the two-colour mark, with PNG sizes for browsers and devices. The supplied full lab logo remains unchanged.
- Social preview: original artwork with exact typeset lab and university names; /brand/social-card.png at 1200 by 630.
- Icons and scientific lattice illustrations: native SVG code. No external icon/photo CDN or font service is required.
- Motion: scroll-based scale chapters, progressive reveal, gentle artwork drift, icon microinteractions, floating compressed navigation and brief native page transitions. The system reduced-motion preference disables decorative motion. There is no artificial loading delay or looping full-page loader.
- Real-time multi-user collaborative animation is not included: it would require presence/session infrastructure with a defined research use case. The scale explorer is local to each visitor and does not imply live collaboration.
